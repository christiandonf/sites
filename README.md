# Repositório de Binários de Produção

## 📦 Sobre este repositório

Este repositório foi criado com um propósito bem específico: armazenar os binários compilados dos sites que serão utilizados em ambiente de produção.

Em vez de conter o código-fonte dos projetos, aqui você encontrará apenas os arquivos já processados, otimizados e prontos para serem publicados.

## 🚀 Objetivo

O principal objetivo deste repositório é servir como um ponto central para:

- Armazenar versões compiladas dos sites
- Facilitar o deploy em ambientes de produção
- Manter um histórico das builds geradas
- Separar claramente código-fonte de artefatos finais

## ⚠️ Observações importantes

- Este repositório **não deve conter código-fonte**
- Alterações manuais nos arquivos compilados devem ser evitadas
- Sempre que possível, as atualizações devem vir de um processo automatizado (CI/CD)

## 🧩 Em resumo

Este é um repositório que conterá os binários compilados dos sites para produção, garantindo organização, rastreabilidade e uma separação clara entre desenvolvimento e entrega final.
